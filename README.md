### Now

**[sweap.it](https://github.com/nKOxxx/sweap.it)** — just launched. Weigh your AI agent's memory store in 30 seconds, see what dead weight costs at your own model's rates, diet it out reversibly. Local-only, stdlib-only, no network:

```bash
curl -sL https://raw.githubusercontent.com/nKOxxx/sweap.it/main/cli/weigh_cc.py | python3
```

Read-only — it prints, it doesn't touch. Run it and [post your receipt](https://github.com/nKOxxx/sweap.it/issues/new?template=post_your_receipt.md).
